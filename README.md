# overlay-assets

Asset e libreria (`overlay_kit.py`) usati da Claude per creare gli overlay dei video di Abcia2.

- `overlay_kit.py`: funzioni per card, frecce, chip, griglie, transizioni.
- `assets.zip`: tutte le cartelle qui sotto in un unico file (scaricato da `setup()`).
- `icons/`, `logos/`, `emoticons/`, `bracelets/`, `beads/`, `characters/`, `abcia2_static_avatars/`, `abcia2_assets/`: asset singoli.

Per aggiungere un asset: mettilo nella cartella giusta con un nome descrittivo in inglese
(es. `icons/star_purple.png`) e rigenera `assets.zip`, oppure caricalo direttamente in chat.
